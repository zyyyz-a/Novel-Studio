# 普通用户使用指南

1. 下载仓库 ZIP，解压，双击 index.html。推荐最新版 Chrome / Edge，无需 Obsidian。
2. 初次打开可看到“北境纪元”演示小说。
3. 从“世界观”添加地点，在“人物关系”建立人物档案和关系。
4. 到“章节管理”新建场景、输入冲突和正文；在“剧情因果”将真正有因果的两个场景连起来并写明理由。
5. 到“时间线”确认事件排列；它按 chronologicalOrder（有值时）或 sequence 展示，不自动推算架空历法。
6. 在“DeepSeek 顾问”复制审查文本，自行粘贴到 DeepSeek。原型不会调用在线 AI。
7. 经常按“导出备份”保存 JSON，并保留原始稿件。

## 快捷键

Alt+1 总览；Alt+2 人物；Alt+3 剧情因果；Alt+4 时间线；Alt+5 章节；Alt+6 世界观；Alt+7 DeepSeek 顾问。

## StoryLine 项目导入

点击“导入 StoryLine 文件夹”并选择原项目文件夹。当前只读取 .md 的基础信息，导入前会提示数量并要求确认。该操作不会写回原文件，但会**覆盖当前浏览器草稿**，先导出备份。

## 重要限制

浏览器 localStorage 是临时草稿存储，并不等于可靠数据库；清理浏览器数据可能丢稿。本原型目前支持 JSON 导出，不支持 JSON 重新导入。复杂 Markdown 字段也可能不完整。请勿仅凭此原型保存重要独家稿件。

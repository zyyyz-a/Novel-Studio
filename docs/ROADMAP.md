# Novel Studio 研发路线图

以下分为“已完成原型”与“未来开发”，不应将规划功能当成现有功能宣传。

## P0 · 静态中文原型（已完成）

- [x] 独立中文导航与示例作品
- [x] 人物档案及关系图
- [x] 手动设置事件因果关系与图谱
- [x] 时间线、章节场景、世界地点
- [x] StoryLine 部分 Markdown 只读导入
- [x] 本地草稿和 JSON 导出
- [x] 可复制的 DeepSeek 审查提示词（未集成 API）
- [x] 开发文档与基础语法检查

## P1 · 可恢复的数据工具（优先）

- [ ] JSON 备份恢复与预览
- [ ] 多作品隔离与切换
- [ ] 标准 YAML 导入、复杂字段保留与错误报告
- [ ] 事件/人物关系编辑与删除、因果循环提示
- [ ] 自动保存与版本快照
- [ ] 浏览器端端到端测试与无障碍改进

验收：重要数据能够导出、恢复、回滚，不会静默丢失。

## P2 · 正式桌面工作台

- [ ] Tauri 2 + React + TypeScript 工程
- [ ] SQLite 本地数据库与事务写入
- [ ] Windows / macOS 安装包
- [ ] 丰富的世界/国家/势力/人物关系图
- [ ] 独立场景编辑器和双时间线
- [ ] StoryLine 数据兼容导入与导出

验收：不依赖 Obsidian，普通作者能双击软件启动并安全保存作品。

## P3 · DeepSeek 逻辑顾问

- [ ] 安全管理 API 密钥
- [ ] 用户授权的项目资料检索
- [ ] 人物认知、时间、世界规则、剧情因果审查
- [ ] 审查证据来源、问题级别和建议
- [ ] 作者批准后才允许改动资料
- [ ] AI 关闭时仍能完整使用

## P4 · 高级世界模拟

- [ ] 人物状态随场景时间变化
- [ ] 事件修改后的连锁影响追踪
- [ ] 伏笔全生命周期和跨卷分析
- [ ] 因果图导出、知识库报告

不计划开发“一键自动生成整部小说”作为核心产品功能。
